# SimpleStore

SimpleStore is an e-commerce web application built with React and TypeScript. Users can browse products, search by name, filter by category, add items to their cart, update quantities, and complete a checkout.

## Features

- Browse products
- Search products
- Filter by category
- Shopping cart
- Update item quantities
- Remove items from cart
- Checkout functionality

## Technologies Used

- React
- TypeScript
- Redux Toolkit
- React Query
- React Router
- Axios
- CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```
